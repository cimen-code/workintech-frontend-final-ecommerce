# Workintech Frontend Final — E-Commerce

Workintech frontend final projesi (T01–T23).

## Çalıştırma

```bash
npm install
npm run dev
```

Site `http://localhost:5173` adresinde açılır. Varsayılan API `https://workintech-fe-ecommerce.onrender.com` adresidir.

[Kendi backend'imiz](https://github.com/cimen-code/workintech-backend-final-ecommerce) ile çalıştırmak için:

```bash
VITE_API_URL=http://localhost:8080 npm run dev
```
